# PeerStack 🚀

AI-based Interview Practice Platform

## 🔥 Features
- Role-based interview (Frontend, Backend, AI/ML, HR)
- Timer-based interview system
- Auto submission
- AI-based evaluation
- Interview history tracking

## 🛠 Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB

## ⚙️ How to Run

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm start
